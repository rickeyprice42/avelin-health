# Каталог ХлебСоль из Купера

Прототип для Windows 10/11 и Python 3.10+. Исходный магазин: https://web.kuper.ru/hlebsolx5/c?sid=70307

## Ночной режим через Opera GX

Теперь есть расширение в папке `extension` и локальный помощник. Оно использует
обычную браузерную сессию и общие парсеры, а не отдельный автоматический профиль.
Процесс: выбранные вкладки Kuper/Fix Price → ассортимент Слаты → очереди карточек
→ КБЖУ → CSV/XLSX и база Avelin. Отдельно скачивать и импортировать пакеты не нужно.

1. Из корня проекта запустите `Ночной сбор каталога.cmd`. Либо выполните
   `python scripts/launch_catalog_collector.py`. Откроется локальная инструкция с
   папкой расширения и ключом подключения. Окно помощника оставьте работающим.
2. В Opera GX откройте `opera://extensions`, включите режим разработчика и нажмите
   «Загрузить распакованное расширение». Выберите `kuper_catalog_prototype/extension`.
3. Вставьте ключ из локальной инструкции в окно расширения и проверьте подключение.
4. Откройте вкладки нужных магазинов Kuper и Fix Price. В Kuper заранее выберите
   магазин и адрес доставки; проверьте город Fix Price. Отметьте вкладки в расширении
   и нажмите «Обновить товары → собрать КБЖУ». Слату можно включить отдельным флажком.
5. Если Kuper не дал автоматически захватить запрос, один раз нажмите продуктовую
   категорию в его рабочей вкладке. На этот шаг отводятся две минуты. Повторная
   авторизация или CAPTCHA могут потребовать участия человека.

По умолчанию результаты сохраняются в `Каталоги магазинов` в корне проекта.
Для другой папки: `python scripts/launch_catalog_collector.py --output "C:\путь\каталоги"`.
Компьютер не должен уходить в сон, браузер и рабочие вкладки должны оставаться
открытыми. Ограничения 250 карточек нет: обрабатывается вся очередь один раз.
Свежие проверенные КБЖУ моложе 30 дней переиспользуются; флажок «Перечитать даже
свежие КБЖУ» принудительно обновляет их тоже. При отсутствии КБЖУ карточка остаётся
в очереди, цифры не придумываются.

Очередь и результаты сохраняются в хранилище расширения каждые 10 карточек;
каждые 50 и в конце этапа данные импортируются локальным помощником. После закрытия
вкладки, остановки или перезапуска браузера нажмите «Продолжить сохранённый сбор».
Может повториться обработка последних девяти карточек. Остановленные или неполные
каталоги не заменяют прежний ассортимент; исчезнувшие товары удаляются из CSV и
становятся недоступными агенту только после подтверждённого полного сбора.

У Слаты автоматически обновляются товары и цены; многие её товары пока не имеют
КБЖУ и ссылки на поддерживаемую карточку. Гарантировать полное заполнение КБЖУ или
завершение за одну ночь нельзя: это зависит от источника и проверок сайтов.

Помощник слушает только `127.0.0.1:8767`, требует ключ из `.local/catalog-collector.json`
и не экспортирует cookies/заголовки браузера. После изменения общих парсеров выполните
`python kuper_catalog_prototype/build_extension.py` и перезагрузите расширение.

Проверки без реальных сайтов:

```powershell
node kuper_catalog_prototype/test_night_run.mjs
node kuper_catalog_prototype/test_extension.mjs
python kuper_catalog_prototype/test_companion.py
```

## Оконное приложение — прежний способ

Для обычной работы VS Code не нужен. Дважды щёлкните файл `Каталог магазинов.bat` на рабочем столе. В окне программы:

1. Добавьте один или несколько HAR-файлов либо целую папку.
2. Выберите папку результатов.
3. Нажмите **Импортировать и создать Excel**.

Программа создаёт отдельные CSV и XLSX для каждого найденного магазина, а также `Все магазины.csv` и `Все магазины.xlsx`. Общий Excel содержит отдельный лист для каждого магазина. Повторный импорт обновляет товары и сохраняет ручные поля из существующих CSV.

Файл `Отчёт импорта.txt` перечисляет магазины и категории, для которых в HAR отсутствуют страницы.

На текущем этапе автоматически распознаются HAR каталога Kuper, включая разные магазины и разные `store_id`. Большие HAR читаются потоково и не загружаются в память целиком.

Кнопка **«Настроить автосбор Kuper»** создаёт одну закладку для Пятёрочки и Хлеб&Соли. Откройте нужный магазин в обычном браузере, проверьте адрес, нажмите закладку и затем один раз выберите любую продуктовую категорию. Помощник получает свежие параметры текущей сессии, сам обходит продуктовые категории и скачивает обезличенный файл `*.complete.har`. Cookies, CSRF-токен и служебные заголовки в файл не записываются. Добавьте HAR в программу и импортируйте обычной кнопкой. Полный автосбор заменяет старый ассортимент соответствующего магазина, сохраняя ручные заметки и КБЖУ у оставшихся товаров.

Кнопка «Обновить Слату автоматически» собирает все страницы 11 продуктовых разделов без HAR и обновляет `Слата.csv`, `Слата.xlsx` и общий каталог. Edge работает в фоновом режиме. Обычно полное обновление занимает несколько минут и зависит от скорости сайта. Исчезнувшие из каталога товары «Слаты» удаляются, а ручные поля у оставшихся товаров сохраняются.

Кнопка **«Настроить автосбор Fix Price»** открывает локальную страницу с зелёной закладкой-помощником. Один раз перетащите её на панель закладок Opera GX. После этого откройте обычный каталог Fix Price, проверьте город и нажмите закладку: она обойдёт все страницы внутри уже работающей браузерной сессии и скачает один файл `fixprice_pages_….json`. Импортируйте его кнопкой **«Импорт Fix Price»**. Полный JSON-пакет заменяет старый ассортимент Fix Price, сохраняя ручные заметки и КБЖУ у оставшихся товаров.

Кнопка **«Импорт Fix Price»** принимает JSON автосбора и остаётся совместимой со старым резервным способом: можно выбрать сохранённые вручную `.html`/`.htm`. Адаптер читает цены из встроенного состояния Nuxt 2.

## Сбор КБЖУ

Кнопка **«Подготовить сбор КБЖУ»** сначала проверяет происхождение и физическую согласованность существующих значений. Результаты старого браузерного парсера переносятся в `КБЖУ карантин.csv`, а исходные CSV/XLSX и кэш сохраняются в папке `Резервная копия КБЖУ …`. Затем программа создаёт две очереди: `КБЖУ очередь Kuper.json` и `КБЖУ очередь Fix Price.json`. Одновременно открывается локальная страница с зелёной закладкой **«Собрать КБЖУ»**. Старую версию закладки удалите и перетащите новую кнопку на панель закладок.

Для Kuper откройте обычный каталог `web.kuper.ru`, нажмите закладку и выберите очередь Kuper. Каталог и публичные карточки находятся на разных поддоменах, поэтому закладка сначала откроет первую карточку на `kuper.ru/products/...`. После её загрузки нажмите закладку ещё раз и повторно выберите ту же очередь — начнётся сбор. Для Fix Price достаточно открыть `fix-price.com`, нажать закладку и выбрать очередь Fix Price. Введите «все» для полного прохода либо нужное число: верхнего ограничения 250 больше нет. Прогресс сохраняется в текущем браузере после каждой карточки; есть кнопка «Остановить и сохранить». Если хранилище страницы переполнится, сбор остановится и скачает накопленный пакет. Для больших ночных очередей предпочтительно расширение. Если карточки остались, снова нажмите закладку и выберите уже скачанный пакет. Временно нераспознанные карточки перемещаются в конец очереди. Не закрывайте вкладку во время прохода.

Затем нажмите **«Импорт КБЖУ»** и выберите накопленный пакет или несколько пакетов. Программа принимает только пакеты текущего парсера `nutrition-v2`: каждый макронутриент должен находиться в физически возможном диапазоне, сумма БЖУ не должна превышать массу продукта, кДж не принимаются за ккал, а калорийность должна согласовываться с БЖУ. Старые пакеты и сомнительные строки отклоняются, а не попадают в каталог или кэш. После проверки программа обновит CSV/XLSX и сохранит результаты в `КБЖУ кэш.json`.

В каталоге используются поля `белки`, `жиры`, `углеводы`, `ккал`, `кбжу_на`, `источник_кбжу`, `кбжу_статус`, `кбжу_проверено_utc` и `состав`. Значения принимаются только полным комплектом из карточки магазина; программа не придумывает КБЖУ по названию. Подозрительное расхождение калорий с расчётом по БЖУ отмечается статусом для ручной проверки, но исходные цифры магазина не исправляются. У «Слаты» большинство каталожных ответов пока не содержит ни КБЖУ, ни отдельной ссылки на карточку, поэтому её товары остаются на ручное заполнение либо будущий источник по штрихкоду.

Кнопки «Kuper», «Бристоль», «Слата», «Красное&Белое» и «Fix Price» в блоке «Открыть каталог» открывают сайты вручную. В Kuper сначала выберите адрес и магазин. Бристоль и Красное&Белое пока блокируют автоматический браузер.

## Импорт из HAR (рекомендуемый режим)

Этот режим не запускает Playwright и не обращается к сайту. Откройте Kuper в обычном Edge, затем DevTools → Network → Fetch/XHR. Перейдите в нужные категории и прокрутите товары до конца, после чего выберите **Save all as HAR with content**. HAR содержит данные локальной браузерной сессии: не публикуйте и не пересылайте его посторонним.

Поместите HAR рядом со скриптом и выполните:

```powershell
.\.venv\Scripts\python.exe kuper_parser.py --har kuper_categories.har
```

Несколько записей можно объединить за один запуск. Если первый HAR содержит ответ с деревом категорий, скрипт возьмёт из него русские названия:

```powershell
.\.venv\Scripts\python.exe kuper_parser.py --har web.kuper.ru.har kuper_categories.har
```

Можно также передать папку: скрипт прочитает все файлы `*.har` непосредственно в ней. Повторный импорт обновляет цены и известные поля, удаляет дубли и сохраняет вручную заполненные `использовать`, `заметка` и БЖУ. Скрипт сверяет записанные страницы с `total_pages` и предупреждает о непролистанной до конца категории. Чтобы указать другой CSV, добавьте `--output путь.csv`.

## Прямой запуск браузера (экспериментальный режим)

Откройте PowerShell в папке с `kuper_parser.py` и выполните:

```powershell
py -m pip install playwright
py -m playwright install chromium
py kuper_parser.py
```

Откроется обычное видимое окно Microsoft Edge. Если сайт просит выбрать город или адрес, укажите свой магазин. Скрипт проходит по ссылкам каталога, прокручивает страницы и создаёт `hlebsol_catalog.csv`. Excel 2007 открывает этот CSV с разделителем `;` и кодировкой UTF-8 с BOM. После правок в Excel сохраняйте файл как CSV UTF-8; при работе с версиями Excel без такого варианта удобнее редактировать его в LibreOffice или текстовом редакторе с UTF-8. Не открывайте CSV в Excel во время обновления.

По умолчанию используется Edge и отдельный профиль `.kuper_edge_profile`. Для возврата к Chromium Playwright запустите `py kuper_parser.py --browser chromium --profile .kuper_browser_profile`.

Если автоматический обход пропускает категории, попробуйте ручной режим:

```powershell
py kuper_parser.py --manual
```

Переходите по нужным категориям в открывшемся браузере, дождитесь товаров и нажмите Enter в PowerShell. Повторный запуск обновляет цены и известные поля, сохраняя `использовать`, `заметка` и БЖУ. Можно задать другой файл через `--output путь_к_файлу.csv`; `--max-pages 80` и `--scrolls 12` ограничивают объём обхода.

Файл `hlebsol_catalog.requests.json` содержит только пути JSON-запросов, в ответах на которые обнаружены товары, и счётчики; токены, cookie и полные ответы не сохраняются. Папки `.kuper_edge_profile` и `.kuper_browser_profile` хранят локальное состояние браузеров: не пересылайте их никому.

## Ограничения прототипа

Купер отклоняет доступ из некоторых сетей. При экране «Отключите VPN» или другой проверке скрипт останавливается: обход защиты не предусмотрен. Ассортимент и цены зависят от выбранного магазина, адреса и времени. Карточки без распознанной цены или товары, которые сайт не загрузил при прокрутке, могут отсутствовать. JSON сайта может изменить структуру; сверьте несколько категорий и цен вручную. БЖУ не выводятся из названия и заполняются только вручную на этом этапе. При ручном режиме записываются товары из JSON-ответов; если сайт не отдаёт распознаваемый JSON, используйте обычный обход.

Если запуск закончился сообщением «Товары не найдены», пришлите **только** файл `hlebsol_catalog.requests.json` и текст ошибки (без папки браузерного профиля). Для доработки извлечения может понадобиться обезличенный пример одного ответа из DevTools, но не экспорт браузерных cookie или полных сетевых логов.
