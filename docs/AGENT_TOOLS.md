# Инструменты агента Avelin Health

Сейчас модель получает шесть инструментов. Пользователь пишет обычный вопрос в чате; модель выбирает функцию и отвечает по её результату.

| Инструмент | Что делает | Пример вопроса |
|---|---|---|
| `get_daily_summary(date)` | Сводка за конкретный день: тело, питание, активность, сон, пульс, источники и пропуски. Без даты — последний импортированный день. | «Покажи итоги за 3 октября: шаги, сон и питание». |
| `get_period_summary(days, end_date)` | Средние, минимум, максимум и изменения за 1–90 дней; отдельно показывает покрытие данных. | «Как изменился вес за последние 30 дней и за сколько дней есть измерения?» |
| `get_health_summary(days)` | Краткие средние, минимум и максимум по имеющимся показателям за 1–90 дней до последней даты импорта. | «Дай краткую сводку активности за неделю». |
| `get_nutrition_gap(day, calorie_target, protein_target)` | Остаток калорий и белка относительно явно заданных целей. | «Моя цель — 2300 ккал и 160 г белка. Сколько оставалось за 3 октября?» |
| `search_store_products(stores, query, limit)` | Поиск товаров в импортированном каталоге выбранных магазинов: название, упаковка, цена и ссылка. | «Найди творог в Пятёрочке и Слате, покажи пять вариантов». |
| `get_user_profile()` | Рост, цель, цели питания из БД и последние 20 ручных измерений тела. | «Какая цель у меня записана и когда я последний раз измерял талию?» |

## Ограничения для тестирования

- Даты по умолчанию привязаны к последнему импорту, а не к текущему календарному дню.
- Тренировки пока не импортируются как полноценные записи и возвращаются как недоступные.
- Инструмент профиля пока не возвращает аллергии, время готовки и магазины, хотя форма их сохраняет. Агенту нужно уточнять их в диалоге.
- Цели из экрана «Питание» пока сохраняются в браузере; агент читает цели из БД. До синхронизации указывайте цели в вопросе.
- `get_nutrition_gap` в текущей реализации использует ноль в расчёте остатка при отсутствующем потреблении; поля фактического потребления остаются пустыми. Безопаснее запросить дневную сводку и не трактовать этот остаток как подтверждённый.
- Поиск выполняется по сохранённому каталогу: он не проверяет текущую цену или наличие на сайте магазина. Подтверждённых КБЖУ в результате этого инструмента нет.
- Инструментов сохранения рецепта, списка покупок, памяти и уведомлений пока нет.

## Ollama

Интеграция использует [нативный API чата](https://docs.ollama.com/api/chat) и [вызовы инструментов](https://docs.ollama.com/capabilities/tool-calling). Ключ хранится только на backend в игнорируемом `.local/llm.json` или в `OLLAMA_API_KEY`.

Провайдер выбирается явно через `AVELIN_LLM_PROVIDER` или локальную настройку. При выборе Ollama ошибки не приводят к переключению на OpenAI. В ответе API возвращаются имена исполненных инструментов (`usedTools`), без содержимого результатов и ключей.

Ollama Cloud обрабатывает сообщения и результаты выбранных инструментов в облаке; это не локальная модель на компьютере.
